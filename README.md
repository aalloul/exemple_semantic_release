# Exemple d'utilisation de semantic-release

Ce dépôt est un exemple pratique montrant comment mettre en place et utiliser [semantic-release](https://github.com/semantic-release/semantic-release) pour automatiser la gestion des versions et la publication de vos projets.

## Qu'est-ce que semantic-release ?

`semantic-release` automatise l'ensemble du processus de publication d'un package. Il détermine automatiquement le prochain numéro de version en se basant sur les messages de commits (selon la convention [Conventional Commits](https://www.conventionalcommits.org/)), génère les notes de version, et publie la nouvelle version.

## Contenu du dépôt

Ce dépôt illustre une configuration minimale et fonctionnelle de `semantic-release`, incluant :

- La configuration de base
- L'intégration avec une pipeline CI/CD
- La gestion automatique des versions (`patch`, `minor`, `major`)

## Prérequis
- Un compte GitHub avec les permissions adéquates
- Un ordinateur avec Git installé pour pouvoir éditer le code et le pousser vers votre dépôt GitHub
